# 뽀모도로 타이머

클래식 음악과 백색 소음이 함께하는 뽀모도로 타이머. 브라우저에서 동작하고 음원은
한 번 내려받아 로컬에 보관합니다.

## 시작하기

```bash
python launcher.py
```

첫 실행 시 `.venv` 를 자동으로 만들고 의존성을 설치한 뒤 브라우저를 엽니다
(<http://127.0.0.1:8025>). 음원은 백그라운드로 내려받으므로 **타이머는 즉시 사용할 수
있고, 곡은 준비되는 대로 하나씩 재생 목록에 들어옵니다.**

```bash
python launcher.py --no-browser    # 브라우저 자동 열기 없이
python launcher.py --no-media      # 음원 자동 내려받기 없이
python launcher.py --port 9000     # 포트 변경
python launcher.py --host 0.0.0.0  # LAN 개방 (아래 주의사항 참고)
```

## 기능

### 사이클 세트
한 세트는 **집중 한 번 + 뒤따르는 휴식 한 번**입니다. 기본은 1세트(집중 25분 / 휴식 5분)이고,
설정에서 세트를 원하는 만큼 추가·복제·삭제하고 순서를 바꿀 수 있습니다.

```
세트1  집중 25분 → 휴식 5분
세트2  집중 25분 → 휴식 5분
세트3  집중 50분 → 휴식 15분     ← 이런 계획도 그대로 표현됩니다
```

반복을 켜면 마지막 세트가 끝난 뒤 다시 첫 세트로 돌아갑니다.

### 오늘 할 일
타이머 아래에 할 일 목록이 있습니다. 하나를 고르면 그 이름이 카운트다운 아래에 뜨고,
집중을 완료할 때마다 그 작업 이름이 세션 기록에 함께 남습니다.

> **할 일을 적지 않아도 됩니다.** 목록이 비어 있어도 시작 버튼은 그냥 눌립니다.
> 작업 입력을 강제하면 "일을 미루는 대신 타이머 켜는 걸 미루게" 되기 때문입니다.

### 음원 검색
음악 탭에서 **archive.org 의 퍼블릭 도메인·CC 음원을 검색해 바로 추가**할 수 있습니다.
앨범을 펼쳐 원하는 곡만 골라 집중/휴식 목록에 담으면 자동으로 내려받습니다.

한국어로 검색하면 영어로 바꿔서 찾고 무엇으로 바꿨는지 알려줍니다
(`'쇼팽 야상곡' → Chopin Nocturne 으로 검색했습니다`). archive.org 가 한국어를 지원하지
않기 때문입니다 — 그대로 넘기면 K-pop 커버가 나옵니다.
추천 검색(집중용 피아노 · 바흐 · 쇼팽 · 바로크 · 실내악 · 군악대)도 있습니다.

라이선스는 배지로 표시하고, **확인되지 않았거나 NC/ND 인 음원은 추가할 수 없습니다.**
검색으로 추가한 곡은 기본 음원 목록과 별도로 보관되므로 음원 목록을 다시 만들어도 남습니다.

### 음악
- 집중용과 휴식용 재생목록이 따로 있고, 어떤 곡을 어디에 넣을지 직접 고를 수 있습니다
- **순서대로 / 무작위** 재생 (플레이어의 🔁 / 🔀 버튼, 단축키 `O`)
- 목록에서 **곡 제목을 누르면 그 곡부터 재생**되고, 다시 누르면 정지됩니다
- 재생 중에는 화면 아래(음악 탭) · 플레이어 바(타이머 화면)에 **실시간 주파수 막대**가
  움직여 실제로 소리가 나가고 있는지 눈으로 바로 확인할 수 있습니다
- 음악만 따로 일시정지할 수 있습니다 (⏸ 버튼, 단축키 `P`)
- **새로고침해도 듣던 곡의 그 지점부터 이어집니다**
- 내 PC 의 음원을 파일 업로드하거나 폴더째 가져올 수 있습니다

### 백색 소음
음악과 **별개 레이어**라 소음만 틀거나 클래식 위에 얹어 쓸 수 있습니다.
브라운·핑크·백색 노이즈와 빗소리·파도·선풍기 소리를 **실시간으로 합성**하므로
파일을 받지 않습니다.

> 소음이 집중력을 "높여" 주지는 않습니다. 실제로 확인된 효과는 **주변 말소리와 갑작스러운
> 소리를 덮어** 주의를 빼앗기지 않게 하는 것입니다. 기본값이 백색이 아니라 브라운인 것도
> 백색 소음이 고역이 강해 오래 들으면 귀가 쉽게 피로해지기 때문입니다.

### 설정
자주 바꾸는 것만 앞에 두었습니다 — **사이클 세트 · 소리 · 기록 · 화면** 네 묶음입니다.
음악 음량, 소음 켜기·종류·음량, 재생 순서는 **타이머 화면에서 바로** 조절하므로 설정에
중복해 두지 않았습니다. 거의 안 바꾸는 항목(중단 정책, 페이드, 화면 켜짐 유지, 탭 아이콘,
초기화)은 **"고급 설정"** 안에 접어 두었습니다.

### 기록
오늘 완료한 개수·총 집중 시간·목표 진행률, **날짜별 세션 목록**(시각·길이·작업 —
달력에서 과거 날짜를 골라 그날의 기록도 볼 수 있습니다), 최근 7일 그래프,
**기록이 있는 날만 보여주는** 지난 기록 표, 그리고 **CSV 내보내기**(엑셀에서 한글이
깨지지 않습니다). 중도 포기한 세션은 개수에 넣지 않고 따로 표시합니다.

연속 달성 일수는 일부러 **작게** 표시합니다. 스트릭을 크게 띄우면 성취감이 아니라
손실 회피로 바뀌고, 오래된 연속이 끊겼을 때 이탈로 이어진다는 조사 결과가 있습니다.
새벽까지 일한다면 설정에서 **하루 시작 시각**을 바꿀 수 있습니다(기존 기록도 함께 재계산됩니다).

### 단축키
| 키 | 동작 |
|---|---|
| `Space` | 시작 / 일시정지 |
| `S` / `R` | 건너뛰기 / 현재 구간 처음으로 |
| `E` | 5분 연장 |
| `F` / `Esc` | 집중 모드 켜기 / 끄기 |
| `P` / `N` | 음악 일시정지 / 다음 곡 |
| `O` / `M` | 재생 순서 / 음소거 |
| `W` | 백색 소음 |
| `1` `2` `3` `4` | 타이머 / 기록 / 음악 / 설정 |
| `?` | 단축키 도움말 (설정 → 고급 설정에도 있습니다) |

## 음원 출처와 라이선스

모든 음원은 저작권이 만료했거나 자유 라이선스로 공개된 녹음입니다.
**작곡이 퍼블릭 도메인이어도 녹음은 별개의 저작물**이므로, 녹음 자체가 자유로운 것만 씁니다.

| 구분 | 출처 | 라이선스 |
|---|---|---|
| 집중 | 바흐 평균율 1권 · 골드베르크 변주곡 · 푸가의 기법 (Kimiko Ishizaka 외) | CC0 / PD Mark |
| 집중 | 쇼팽 모음 (Musopen) | CC0 |
| 휴식 | 미 공군·해병대·해군 군악대 연주 | **퍼블릭 도메인** (미국 정부 저작물) |

집중은 솔로 피아노 위주로 균질하고 조용한 곡을, 휴식은 관현악의 밝고 활기찬 곡을 담아
편성과 기분이 확실히 대비되도록 구성했습니다.

확장 세트에 CC BY-SA 음원이 포함될 경우 **저작자 표시가 의무**이며, 앱의 음악 화면 하단
"음원 출처 및 라이선스" 에 표시됩니다. 받은 파일은 재인코딩하지 않고 그대로 보관합니다.

> **AccuRadio 연동은 하지 않습니다.** 이용약관 §VI/§VII 가 제3자 애플리케이션을 통한 접근을
> 명시적으로 금지하고, 스트림 URL 자체도 제공하지 않습니다. 선곡 방향의 참고로만 삼았습니다.
> 같은 이유로 YouTube 숨김 플레이어, SomaFM, 라디오 스트림도 사용하지 않습니다.

음원 목록을 다시 만들려면:

```bash
.venv/Scripts/python.exe qa/build_catalog.py
```

## 음악과 집중력 — 정직한 근거

과장하지 않기 위해 밝혀 둡니다.

**근거가 약한 통설**: "60bpm 바로크가 알파파를 유도한다"는 1970년대 암시교수법에서 온
이야기로 통제된 연구 근거가 없습니다. 모차르트 효과도 이후 메타분석에서 사실상 사라졌습니다.

**실제로 뒷받침되는 것** — 그리고 이 앱이 반영한 것:

| 근거 | 반영 |
|---|---|
| 가사가 있으면 독해·언어기억이 확실히 저하된다 | 전곡 **기악곡만**. 성악곡 제외 |
| 템포보다 **음량**이 중요하다 (크고 빠른 음악에서 독해력 최악) | 기본 음량을 낮게(55%) 두고 슬라이더를 항상 노출 |
| 배경음악의 전체 효과는 메타분석상 영(null)이고 독해는 오히려 방해받는다 | **무음 모드**를 1급 옵션으로 제공 |

전통적인 "바로크 느린 악장" 선곡은 결과적으로 맞지만 이유가 다릅니다 — 느리고 조용하고
가사 없는 곡을 고르게 되기 때문입니다. 잘 맞지 않는다면 음량을 더 낮추거나 무음 모드를 켜세요.

## 데이터

- `data/` — 설정·기록·재생목록 (JSON)
- `media/` — 내려받은 음원

둘 다 git 에 올라가지 않습니다. 기록을 지우려면 설정 화면의 "기록 전체 삭제" 를 쓰세요.

## LAN 접속 주의

`--host 0.0.0.0` 으로 열면 같은 네트워크의 다른 기기에서 접속할 수 있지만:

- **인증이 없습니다.** 파일 업로드와 폴더 탐색 엔드포인트가 함께 노출됩니다
- `http://` 는 secure context 가 아니라 다른 기기에서는 **알림·화면 켜짐 유지가 동작하지 않습니다**

신뢰할 수 있는 가정·사무실 네트워크에서만 사용하세요.

## 문제 해결

**소리가 안 나요** — 브라우저가 첫 제스처 전까지 자동 재생을 막습니다. 화면을 아무 데나
한 번 클릭하거나 시작 버튼을 누르면 조용히 풀리고 이어서 재생됩니다(따로 누를 배너는
없습니다). 그래도 안 들리면 음악 탭에서 곡을 눌러 보세요 — 재생 바의 막대가 **움직이면**
재생 엔진은 정상이라 스피커/시스템 볼륨/탭 음소거 쪽 문제이고, **안 움직이면** 재생 자체가
안 되고 있는 것이니 어떤 곡인지 알려 주세요.

**음원 내려받기가 자꾸 실패해요** — Wikimedia 는 연속 다운로드를 제한합니다. 잠시 뒤
"전체 내려받기" 를 다시 누르면 받다 만 파일부터 이어받습니다.

**휴식이 바로 시작되지 않아요** — 일부러 그렇습니다. 자동 시작이 켜져 있어도 20초 유예를
둡니다. 0:00 에 휴식이 곧바로 시작되면 그 앞부분을 하던 일 마무리에 쓰게 되어 5분 휴식이
실제로는 2분이 되기 때문입니다. "지금 시작"을 누르면 바로 넘어갑니다.

**한국어로 검색했는데 결과가 이상해요** — archive.org 는 한국어 메타데이터가 거의 없습니다.
앱이 아는 단어(작곡가·악곡 형식)는 자동으로 영어로 바꿔 주지만, 그 밖의 말은 제외하고
그 사실을 알려 줍니다. 추천 검색 칩을 쓰거나 영어로 입력해 보세요.

**절전에서 깨어났더니 창이 떴어요** — 타이머가 끝난 뒤 2분 넘게 멈춰 있었다는 뜻입니다.
그 시간을 완료로 기록할지 버릴지 고르면 됩니다. 설정에서 기본 동작을 바꿀 수 있습니다.
